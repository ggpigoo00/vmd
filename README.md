# BEANPOLE Flagship VMD

BEANPOLE 2층 플래그십 스토어의 VMD 및 공간 기초설계 프로젝트입니다.

## 프로젝트 기준

- 건물 외곽: 18,000 × 24,000 mm
- 규모: 지상 2층
- 개념 면적: 층별 432㎡, 총 864㎡
- 1층: DISCOVER — 브랜드를 발견하는 첫 경험
- 2층: EXPERIENCE — 브랜드를 경험하고 머무는 공간
- 핵심 장치: 체크 그리드, 자전거 휠, 중앙 보이드

## 폴더 구성

- `assets/drawings/`: 평면도, 단면도, 입면도, 상세도, 설비 개념도
- `assets/presentation/`: 조닝, 콘셉트, 투시도, 최종 발표 패널
- `docs/DRAWING_INDEX.md`: 도면 목록과 용도
- `docs/CLOUD_TASK_PROMPT.md`: Codex Cloud 시작 프롬프트
- `docs/PROJECT_CONSTRAINTS.md`: 작업 시 유지해야 할 기준

## 중요 안내

이 자료는 과제 및 SketchUp 모델링을 위한 개념 기초설계안입니다. 실제 시공, 인허가, 구조, 소방, 피난, 전기 및 공조 설계를 대신하지 않습니다. 모든 치수와 수량은 현장 실측 및 관련 전문가 검토 후 확정해야 합니다.

## Codex Cloud 사용

1. 이 저장소로 Cloud Environment를 생성합니다.
2. 별도의 설치 스크립트나 시작 서비스는 필요하지 않습니다.
3. 환경을 Publish한 뒤 `docs/CLOUD_TASK_PROMPT.md`의 프롬프트로 새 작업을 시작합니다.
