# Recommended first Codex Cloud task

BEANPOLE 플래그십 VMD 기초설계 프로젝트입니다.

`README.md`, `AGENTS.md`, `docs/PROJECT_CONSTRAINTS.md`, `docs/DRAWING_INDEX.md`를 먼저 읽고, `assets/`의 모든 도면과 발표 패널을 검토해 주세요.

다음을 수행해 주세요.

1. 전체 폭 18,000 mm, 깊이 24,000 mm, 보이드 7,200 × 6,000 mm가 도면마다 일치하는지 확인합니다.
2. 1층과 2층의 기둥, 계단, 보이드 위치가 서로 정렬되는지 확인합니다.
3. 공간명, 도면번호, 층 표기, 주요 통로 폭을 점검합니다.
4. AI 이미지 특성으로 발생한 잘못된 숫자나 한글 표기를 파일별로 정리합니다.
5. 결과를 `revisions/YYYY-MM-DD/design-audit.md`에 저장합니다.
6. 원본 이미지는 수정하거나 덮어쓰지 않습니다.

이 자료는 과제 및 SketchUp 모델링용 개념안입니다. 실제 법규 적합성이나 시공 가능성을 확정적으로 판단하지 말고, 전문 검토가 필요한 항목을 별도로 표시해 주세요.
