# Repository instructions

This repository contains architectural concept images and presentation assets rather than executable software.

## Working rules

- Preserve all original files in `assets/`.
- Put revised files in a new `revisions/YYYY-MM-DD/` directory.
- Never overwrite an existing drawing or panel unless the user explicitly requests replacement.
- Treat 18,000 × 24,000 mm as the authoritative overall footprint.
- Keep the 1F concept as `DISCOVER` and the 2F concept as `EXPERIENCE`.
- Keep the central void at 7,200 × 6,000 mm unless the user explicitly changes it.
- Label engineering, fire-safety, accessibility, electrical, HVAC, and quantity information as conceptual and subject to professional review.
- When reporting inconsistencies, identify the exact filename and visible label or dimension.
- Use Korean for user-facing deliverables unless instructed otherwise.

## Validation priorities

1. Overall dimensions and grid consistency.
2. Stair and void alignment between floors.
3. Space names and circulation widths.
4. Drawing numbers and titles.
5. Korean text legibility.
